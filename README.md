# 智驾接管模拟器

第二款游戏。第一人称座舱 3D 小游戏（Three.js），纯静态站点，无构建步骤。

## 玩法

- **第一阶段 · 路口接管**：智驾在红绿灯路口前突然失灵，车辆自动加速到 139km/h 冲向对面的杆子。按住「刹车」控制踏板力度（松开泄力），力度决定制动强度；力度超过 **1612N** 踏板断裂、直接失败；在撞上杆子之前刹停 = 胜利。
- **第二阶段 · 撞毁逃生**：撞上杆子后只有 3 秒，按顺序点对三个按钮——🚪 开车门 → 🏃 快跑！ → 📞 拨打紧急电话（按钮位置每局随机打乱）。第 1、2 步按错或超时 → 车辆着火结局；第 3 步按错 → 新闻播报结局；全部按对 → 留住生命结局。

操作：按住空格 = 刹车；第二阶段可用数字键 1/2/3 按屏幕位置点按钮。

## 在 Cloudflare Pages 部署

1. 打开 Cloudflare 控制台 → Workers & Pages → Create → Pages → Connect to Git
2. 选择本仓库 `zhijiamoniqi`
3. 构建设置：
   - Framework preset：**None**
   - Build command：**留空**
   - Build output directory：**`/`**（根目录）
4. Save and Deploy 即可。站点入口就是仓库根目录的 `index.html`，`lib/three.module.js` 为本地化的 Three.js r160，无需任何后端和环境变量。

## 文件

- `index.html` — 游戏全部代码（场景 + 逻辑 + 合成音效，无外部资源）
- `lib/three.module.js` — Three.js r160（本地副本，避免 CDN 依赖）
